# 第七期样例

先在工作台导入 `data/workbench/import.json`，它包含正常、缺失、冲突三种中文合成数据。
该目录的两个文件是发给 `POST /api/tasks` 的请求，不是商品导入文件。

- `review-request.json`：无需聊天模型的固定整理，必定进入人工复核，可验证批准、拒绝和修改。
- `mcp-skill-request.json`：需要真实模型，读取原生技能并委派评论和规则专项；MCP 需先配置并启动。

两者均没有完整成本参数，因此不会虚构利润。auto 策略会因成本缺失进入复核。
样例复用已有冲突资料：500ml 冷水静置不漏、1L 装汤倾斜漏水；汤的温度没有记录。
两种使用条件不同，不能证明规格导致差异，也不能将“汤”擅自改写成“热汤”。
