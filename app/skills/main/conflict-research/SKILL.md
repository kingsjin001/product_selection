# 冲突与综合研究

先读本文件；出现矛盾时再读 references/checklist.md。
多 Agent 模式只委派一轮 reviews 和 rules 专项，收齐后综合，不重复专项检索。
单 Agent 模式按需使用评论分析与规则核验技能。
冲突保留双方证据 ID，并在 missing_data 写明仍缺少的判别依据。
不编造成本、销量和增长率；利润仅引用确定性计算。
用户偏好只是建议条件，不是商品事实，也不能改变当前商品市场。
对不确定结论给条件与下一步，由应用复核策略决定是否暂停，不自行发布报告。
