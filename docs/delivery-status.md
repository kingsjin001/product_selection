下一期分支从上一期验收提交创建，保留各期可独立查看的代码快照。
`codex/v1` 是收尾时从原始 `v1` 单独创建的补全分支；v2 已含同样的六个漏交文件。
因此没有改写用户原 v1，也没有将第一期指向包含后续功能的提交。
未执行的外部服务、真实模型、故障恢复或效果评测必须在报告中注明，不能用 mock 通过替代。

在 PyCharm 的 Git 分支菜单选择对应分支即可查看；切换前保存自己的未提交修改。
也可执行 `git log --oneline --decorate --all`。这些是本地提交，未推送远程。
各期数据库结构随迁移累计；查看旧分支时不要对当前数据库执行降级或清库，
独立演示旧阶段建议配置独立数据库。
