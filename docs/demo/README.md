## 现场操作脚本

开始前按根 README 启动数据库、API、Worker、分发器和页面，完成索引。
确认三个 Python 进程均读取同一项目根目录配置。

1. **约 30 秒**：展示 `data/workbench/` 的三种合成场景，上传三份文件。
   重复上传展示批次复用；不要修改已有 ID 正文再期待静默覆盖。
2. **约 60 秒**：选择普通商品，先运行 fixed 确认工程链路，
   再选择固定检索综合。展示阶段事件、调用记录、原文引用和缺失项。
   模型实际响应时间不固定，现场等待时可打开已保存的代表性报告。
3. **约 45 秒**：首次网页提交不含成本，先在报告中确认演示成本并生成修订版，
   或打开预先准备的普通报告。展示三种成本情景，提出“基准情景的利润是多少”，
   说明默认追问只是定位报告；真实模型解读是独立请求。
4. **约 45 秒**：将售价 25 改为 26 创建新版本，原基准利润 7.25 USD，
   新版本 8.09 USD，确认父报告编号与旧报告不变。
5. **约 45 秒**：打开第四/六期恢复记录，解释投递中断、重复执行、
   Worker 退出和 SSE 重连。需要现场故障演示时另跑恢复脚本，它会创建并结束专用测试 Worker。
6. **约 30 秒**：展示评测表，说明 43/43 是可解析率而非人工支持率，
   本组数据不能证明自主研究质量更高。

Word 可下载，但本次没有完成打印版式验收；演示时以网页、JSON/Markdown 数字为依据。

## 重新生成视频

```powershell
& D:\Programs\anaconda3\envs\py12\python.exe -m pip install -e '.[demo]'
& D:\Programs\anaconda3\envs\py12\python.exe scripts/make_demo_video.py
```

脚本使用 Windows 微软雅黑字体、仓库内页面截图和已有评测结果，
生成时覆盖本演示 MP4，将中间场景图写入忽略的 `exports/`。
更新截图或数据后应重新逐张检查场景图，避免字幕超出画面或引用过期数字。
