## 已知边界

Windows Worker 使用 solo，验收不是多机高并发容量测试。
模拟进程退出发生在指定提交边界；没有声称对每一条 Python 指令都做过 kill 测试。
在途供应商请求不能保证强制停止或不计费；模型请求并不具有严格一次执行语义。
时间预算从第一次领取开始，停机时间也计入。失败超过预算需新建任务。
旧同步 CLI 仍按单次执行计时；后台任务才使用跨恢复的持久截止时间。
服务尚未提供多用户鉴权，保持回环地址访问。
